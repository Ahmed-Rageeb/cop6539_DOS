5. Findings

Connectivity dominates everything else. At every network size the four topologies separate by orders of magnitude, in the order full < imp2D < 2D < line. Adding a single random long-range edge per node — the only difference between 2D and imp2D — is worth far more than the regular grid structure it is added to. That is the small-world effect appearing in a 25-line change to the neighbour function.

Gossip on a line is a coin flip, not a slow success. The rumour does not simply take longer on a line; it frequently dies out altogether. A node stops transmitting after ten hears, and the node adjacent to a fast talker reaches ten almost immediately, having forwarded the rumour only a handful of times. The frontier then stalls, and what remains is a dead-end node transmitting forever into a neighbour that has already fallen silent. This is why the tables report how many trials converged rather than a bare average.

Push-Sum is accurate exactly where it is fast. On full and imp2D the estimate matches the true average to around 1e-13 — floating-point noise. On 2D and line the relative error rises to roughly 1e-3. The termination rule is local: an actor stops when its own ratio stops moving, which on a slowly-mixing graph happens well before the network as a whole has mixed. Accuracy and speed are not two independent properties here; they are the same property of the topology.

On what s/w converges to. With si = i and wi = 1, the conserved quantity is Σs / Σw = (n+1)/2 — the average, not the sum. The assignment calls s/w the sum estimate; the sum is the ratio times n. Both are printed by the simulator.

Scaling. Across 10 to 100000 nodes, gossip on the full topology fits t ∝ n0.90. A slope near 1 means convergence time grows roughly linearly with the number of actors, which is what a fixed number of rounds costs when each round is O(n) messages spread over a fixed number of cores — the simulator is scheduler-bound, not round-bound.
